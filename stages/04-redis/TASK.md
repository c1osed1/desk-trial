# Этап 4 — redis

Клиент уже дан. Три штуки: лимит, кэш списка, идемпотентность.

Лимит — фиксированное окно, не скользящее. Ключи `rl:…`.

Кэш списка с версией (`tickets:ver`), чтобы на записи не бегать по KEYS. TTL на сам список.

Идемпотентность: пока считается — второй такой же ключ не стартует; если уже есть ответ — отдай его; если упало — ключ можно повторить. Префикс `idem:`.
